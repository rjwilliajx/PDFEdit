# PDFEdit
PDFEdit

Created by Rick Williams

A free desktop PDF editor designed to provide simple PDF editing capabilities without requiring a subscription.

PDFEdit is a simple, local-first PDF editor designed to make common PDF editing tasks as straightforward as possible.

### **Preserve the Original**

PDFEdit intentionally protects the user's original PDF. Rather than overwriting the source document, edited documents are saved as a new PDF using **Save PDF As**. This approach reduces the risk of accidental data loss while preserving the original file as a permanent reference.
Most PDF editors focus on advanced publishing features, cloud services, subscriptions, and enterprise workflows. PDFEdit focuses on the needs of everyday users who need to quickly modify an existing PDF without complexity, advertisements, or recurring fees.

## **Vision**

To provide a fast, intuitive PDF editing experience that allows users to modify PDF documents directly, without requiring the original source file.

## **Goals**

- Edit existing PDF text
- Add new text anywhere in a document
- Insert images and logos
- Add signatures and dates
- Manage pages (insert, delete, reorder, rotate)
- Review documents for spelling and formatting issues
- Operate entirely on the user's device
- Remain free of advertisements and unnecessary bloat

## **Non-Goals**

PDFEdit is not intended to be:

- A cloud document platform
- A collaboration suite
- A document management system
- A subscription service
- An enterprise workflow solution

## **Core Principles**

### **Simplicity First**

Common tasks should require as few steps as possible.

### **Local First**

Documents remain on the user's computer unless they explicitly choose otherwise.

### **User Focused**

The application should prioritize solving real-world document editing problems over adding rarely used features.

### **Honest Functionality**

PDFEdit will preserve formatting whenever possible and clearly communicate limitations when they exist.

## **Why PDFEdit?**

Everyday document editing tasks shouldn't require expensive enterprise software. With PDFEdit, you can:

- **Update a resume date** — Fix employment dates, graduation years, and formatting without starting over
- **Add a bullet to a job description** — Quickly modify job listings without losing the original layout
- **Sign a contractor document** — Add your signature or initials to agreements, contracts, and forms
- **Replace a company logo** — Update branding or correct logos in documents without complex tools
