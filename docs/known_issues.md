# Known Issues

## Current
- Existing PDF text editing not yet implemented
- Save functionality not yet implemented

## Image Decisions
- Image sizes are preset-based, not custom-width
- Small = 75
- Medium = 150
- Large = 300
- X-Large = 500
- Original image size removed
- Aspect ratio preserved
- Phone photo orientation corrected

## QR Code Decisions
- QR codes use image placement logic
- QR codes default to Small size
- QR codes support drag-to-place positioning

## Future Enhancements
- Live placement preview improvements
- White space detection
- OCR support
- Drawn signatures
